# European Top 5 League Stats 2022–23

## Objective

The European Top 5 League Stats 2022–23 project aimed to analyze football statistics from Europe’s top five leagues using Power BI. The goal was to transform raw sports data into interactive dashboards and visual reports to uncover insights about player performance, goals, assists, cards, and overall league competitiveness.

This project strengthened data visualization, dashboard development, and analytical skills while demonstrating the ability to generate meaningful business insights from data.

---

### Skills Learned

- Data cleaning and preprocessing using Power Query.
- Data modeling and relationship building in Power BI.
- Creating interactive dashboards and KPI visualizations.
- Using DAX functions for calculated measures and analysis.
- Data storytelling and insight generation through visual analytics.

---

### Tools Used

- **Power BI** for dashboard creation and visualization.
- **Power Query** for data transformation and cleaning.
- **DAX** for calculated columns and measures.
- **Excel/CSV Datasets** for football statistics analysis.

---

## Steps

Below are the key steps taken in the project:

### 1. Data Collection and Cleaning

Collected football statistics datasets from multiple sources and cleaned the data using Power Query by handling missing values, formatting columns, and preparing the dataset for analysis.

---

### 2. Data Modeling

Built relationships between tables and created an optimized data model for efficient dashboard performance and analysis.

---

### 3. Dashboard Development

Created interactive Power BI dashboards to visualize:

- Top Goal Scorers
- Top Assist Providers
- Club Goal Statistics
- Yellow & Red Card Analysis
- Penalty Performance
- KPI Metrics and Filters

---

### 4. Data Analysis Using DAX

Used DAX measures and calculated columns to generate advanced insights and dynamic visualizations for player and team performance analysis.

---

### 5. Final Outcome

Successfully built an interactive and visually engaging Power BI dashboard that provided meaningful insights into football performance statistics across Europe’s top five leagues during the 2022–23 season.
