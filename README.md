# European Top 5 League Stats 2022–23

## Objective
The European Top 5 League Stats 2022–23 project aimed to analyze football statistics from Europe’s top five leagues using Power BI. The goal was to transform raw sports data into interactive dashboards and visual reports to uncover insights about player performance, team statistics, goals, assists, cards, and overall league competitiveness.

This project enhanced data visualization, analytical thinking, and dashboard development skills while demonstrating the ability to create data-driven insights for sports analytics.

---

## Skills Learned

- Data cleaning and preprocessing using Power Query.
- Data modeling and relationship building in Power BI.
- Creating interactive dashboards and KPI visualizations.
- Using DAX functions for calculated measures and analysis.
- Data storytelling and insight generation through visual analytics.

---

## Tools Used

- **Power BI** for dashboard creation and visualization.
- **Power Query** for data transformation and cleaning.
- **DAX** for calculated columns and measures.
- **Excel/CSV Datasets** for football statistics data.

---

# Dashboard Insights

### 1. Top Goal Scorers
Analyzed the highest goal-scoring players across Europe’s top five leagues to compare attacking performance and consistency.

### 2. Top Assist Providers
Visualized players with the most assists to identify key playmakers and creative contributors.

### 3. Penalty Performance Analysis
Compared penalty attempts and successful penalty goals among top players.

### 4. Club Goal Statistics
Highlighted clubs with the highest number of goals scored during the 2022–23 season.

### 5. Discipline Analysis
Analyzed yellow cards and red cards received by players to evaluate disciplinary records.

### 6. KPI Metrics
Displayed total goals scored and other important football statistics using dynamic KPI cards and filters.

---

## Outcome

Successfully built an interactive and visually engaging Power BI dashboard that provided meaningful insights into football performance statistics across Europe’s top five leagues during the 2022–23 season.
